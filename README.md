# Desafios Target

Este repositório contém a solução dos desafios propostos, desenvolvidos em **Python 3**.

---

## 📌 Visão Geral dos Desafios

### 🔹 Desafio 1: Cálculo de Comissão de Vendedores
- **Descrição:** Lê um arquivo JSON (`data.json`) com registros de vendas de um time comercial e calcula a comissão total acumulada para cada vendedor com base no valor das vendas.
- **Caminho:** `desafio-1/main.py`

### 🔹 Desafio 2: Controle de Estoque
- **Descrição:** Sistema interativo de movimentação de estoque (entrada e saída de produtos) que lê e atualiza os produtos cadastrados no arquivo `estoque.json` e gera registro de movimentações.
- **Caminho:** `desafio-2/main.py`

### 🔹 Desafio 3: Cálculo de Juros por Atraso
- **Descrição:** Recebe o valor original de um título e a data de vencimento, calculando os dias de atraso em relação à data atual e aplicabilidade de multa/juros de 2,5% ao dia.
- **Caminho:** `desafio-3/main.py`

---

## ⚙️ Pré-requisitos e Execução

### Pré-requisitos
- **Python 3.10+** (utiliza bibliotecas nativas como `datetime` e `json`, não necessitando de bibliotecas externas).

---

## 🚀 Como Executar

Execute os comandos a partir da raiz do projeto:

### Rodar Desafio 1:
```bash
python desafio-1/main.py
```

### Rodar Desafio 2:
```bash
python desafio-2/main.py
```

### Rodar Desafio 3:
```bash
python desafio-3/main.py
```
